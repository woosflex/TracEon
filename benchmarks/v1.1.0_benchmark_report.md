This report documents GZip decompression throughput for TracEon v1.1.0 across four synthetic dataset sizes (10 MB – 500 MB compressed). The benchmark measures end-to-end load time (decompress + parse) and reports throughput as **MB of uncompressed data per second**.

## 2. Throughput Analysis

All four dataset sizes achieve **> 290 MB/s** throughput, with the 50 MB dataset peaking at **378 MB/s**.

### Observations

- **Cache-resident datasets (10–50 MB):** Throughput is highest (303–378 MB/s). The 50 MB working set benefits from L3 cache locality on modern x86_64 CPUs.
- **Memory-bound datasets (100–500 MB):** Throughput stabilises around 294–325 MB/s as the working set exceeds L3 cache and becomes RAM-latency-bound.
- **Overall drop from peak:** Only ~22% degradation from 378 MB/s (50 MB) to 294 MB/s (500 MB), indicating efficient prefetching and streaming in zlib-ng.

### Throughput vs Compression Ratio

All files exhibit a consistent compression ratio of approximately **6.0×**, typical of homogeneous genomic FASTQ data with ~150 bp reads.

## 7. Conclusions

1. **All datasets process at > 290 MB/s throughput** — well within the expected range for zlib-ng v2.2.2 with native SIMD instructions.
2. **Near-linear scaling** — no unexpected bottlenecks emerge up to 500 MB compressed (2.9 GB uncompressed).
